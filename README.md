# ZahraaFit v4 — النشر

## المحتوى
```
index.html                    ← البرنامج (يقرأ الصور من img/)
نسخة-مستقلة-للمشاركة.html      ← نسخة الصور مدفونة داخلها (للمشاركة أو العمل بلا إنترنت)
img/                          ← 18 صورة (15 عضلة + شعارين + غلاف)
api/generate.js               ← الذكاء الاصطناعي
api/sheet.js                  ← وسيط قراءة شيت المشتركين
package.json
```

## خطوات النشر على Vercel

### 1) المستودع
ارفعي **محتويات هذا المجلد** إلى مستودع GitHub (`zheerr30/zahraafit` أو مستودع جديد).
من واجهة GitHub: `Add file → Upload files` ثم اسحبي الملفات والمجلدات.

### 2) الربط بـVercel
- من vercel.com اختاري **Add New → Project**
- اختاري المستودع، واتركي كل الإعدادات كما هي (لا يحتاج Build)
- اضغطي **Deploy**

### 3) مفتاح الذكاء الاصطناعي
- في المشروع: **Settings → Environment Variables**
- الاسم: `ANTHROPIC_API_KEY`
- القيمة: مفتاحك من console.anthropic.com
- البيئات: Production + Preview + Development
- ثم **Deployments → آخر نشر → Redeploy** (المتغيّر لا يُفعّل إلا بنشر جديد)

### 4) التحقق بعد النشر
| ما تتحققين منه | كيف |
|---|---|
| الصور | افتحي 🖼️ مكتبة الصور — يجب أن يقول «من الخادم: 18» |
| الجدول | ولّدي جدولاً وتأكدي من ظهور الصور وأزرار ▶ |
| الـPDF | صدّري وتأكدي: لا صفحات فارغة، الغلاف كامل |
| الذكاء | زر 🤖 توليد بالذكاء الاصطناعي |
| المشتركون | 📥 المشتركون ← الصقي رابط الشيت ← سحب البيانات |

## ملاحظات
- **لا ترفعي الصور من داخل البرنامج بعد النشر** — المرفوع محلياً يُحفظ في متصفح جهازك فقط ويغطّي صور الخادم على ذاك الجهاز. صور `img/` تظهر على كل الأجهزة تلقائياً.
- لتبديل صورة: استبدلي الملف في `img/` وأعيدي النشر.
- لتغيير نموذج الذكاء: عدّلي `MODEL` في أعلى `api/generate.js`.
- إذا فشل الذكاء لأي سبب، البرنامج يرجع تلقائياً للتوليد المنطقي ولا يتعطّل.
