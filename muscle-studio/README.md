# MUSCLE STUDIO 3D — استوديو العضلات

استوديو عربي لتلوين العضلات المستهدفة والثانوية على نموذجين تشريحيين ثلاثيي الأبعاد (ذكر وأنثى)، وتصدير رسوم
توضيحية عالية الدقة للمدربين ومعلّمي التشريح. الواجهة عربية بالكامل وباتجاه RTL.

النماذج التشريحية من مشروع **[Open Anatomy 3D](https://github.com/MervinR07/open-anatomy-3d)** برخصة
**CC BY 4.0** — انظر [المصادر والترخيص](#المصادر-والترخيص).

## التشغيل

يتطلب Node.js ‏20.9 أو أحدث.

```bash
cd muscle-studio
npm install        # ينسخ أيضًا مفكّكات Draco/KTX2 إلى public/decoders
npm run dev        # http://localhost:3000
```

| الأمر | الغرض |
| --- | --- |
| `npm run dev` | خادم التطوير |
| `npm run build` ثم `npm start` | بناء الإنتاج وتشغيله |
| `npm test` | اختبارات الوحدة (Vitest)، ومنها تحميل ملفي GLB الأصليين والتحقق من كل عضلة |
| `npm run typecheck` / `npm run lint` | فحص الأنواع و ESLint |
| `npm run e2e:select` | اختبار النقر الحقيقي على كل عضلة في المتصفح (يتطلب Playwright وتشغيل التطبيق) |

## نموذج Open Anatomy 3D

- الملفان الأصليان منسوخان **دون أي تعديل** إلى `public/models/open-anatomy-3d/`
  (`anatomy-male.glb` و`anatomy-female.glb`، من الإيداع `c050aa7b1bc5`)، ومعهما `LICENSE-MODELS.md` و`ATTRIBUTION.md`.
  فهرس البنى الأصلي في `data/models/open-anatomy-3d/catalog.json`.
- كل نموذج مقسّم إلى ستة أجهزة: العضلات، والهيكل العظمي، والجلد، والأعضاء، والأوعية، والأعصاب.
  **تظهر العضلات وحدها عند البدء**، ويمكن إظهار بقية الأجهزة من «الأجهزة التشريحية» في لوحة الإعدادات.
  التلوين متاح للعضلات فقط؛ تمرير المؤشر على عظم أو عضو يعرض اسمه العربي.
- الجلد شفاف ولا يعترض النقر، فيمكن تحديد العضلات من خلاله.
- إذا تعذّر تحميل النموذج تظهر رسالة خطأ واضحة مع زر «إعادة المحاولة»، **ولا يُعرض أي مجسّم بديل**.
  (أُزيل نموذج الاختبار الهندسي السابق من المشروع.)

### ما الذي يحتويه النموذج فعلًا

بعد فحص الملفين وقواعد البناء في المستودع الأصلي (`pipeline/catalog.mjs`):

- **41 شبكة عضلية = 22 وحدة قابلة للتلوين** (19 ثنائية الجانب + 3 على الخط الناصف)، وهي نفسها في النموذجين.
- **عضلات مفردة:** الصدرية الكبرى، وشبه المنحرفة، والدالية (كاملة، دون فصل رؤوسها)، والحجاب الحاجز.
- **مجموعات مدموجة:** مثل «عضلات العضد» (ذات الرأسين + العضدية + الغرابية العضدية + ثلاثية الرؤوس + المرفقية)
  و«عضلات الألوية» و«رباعية الرؤوس» (ومعها الخيّاطية). تلوين المجموعة يلوّنها كاملة.
- **غير موجودة:** العضلة الظهرية العريضة — لا تطابقها أي قاعدة في بناء النموذج، والتحقق البصري يؤكد غيابها.
- لا يمكن فصل المجموعات بدقة: الشبكات المدموجة تحتوي أجزاء منفصلة هندسيًا لكن دون أي تسمية تبيّن أيّها أي عضلة،
  لذلك لم يُعتمد أي تقسيم تخميني.

جدول التغطية الكامل للعضلات المرجعية الـ32 يظهر في صفحة «مكتبة العضلات» داخل التطبيق
(`data/muscles/coverage.ts`): 2 قابلة للتحديد منفردة، و3 «العضلة كاملة فقط» (رؤوس الدالية)، و26 ضمن مجموعات، و1 غير موجودة.

### اختبار التحديد المستقل

- **اختبارات الوحدة** (`tests/openAnatomy.test.ts`) تحمّل الملفين الأصليين في Node وتتحقق من: ربط الشبكات الـ41 كلها،
  وأن لكل وحدة شبكاتها الخاصة غير المشتركة، وصحة الجانب الأيسر/الأيمن، وأن تحديد كل وحدة يلوّن شبكاتها وحدها،
  وأن لكل شبكة في النموذج اسمًا عربيًا.
- **اختبار النقر الحقيقي** (`e2e/select-each-muscle.cjs`) ينقر بالفأرة على كل وحدة من المناظر الأربعة ويتحقق أن
  النقر يحدد تلك الوحدة وحدها ثم يلغيها:

| النموذج | تُحدَّد بالنقر على المجسّم | من القائمة فقط |
| --- | --- | --- |
| ذكر | 21 من 22 | الحجاب الحاجز (داخلي) |
| أنثى | 20 من 22 | الحجاب الحاجز، والكفة المدوّرة (مغطاة في المناظر الأربعة) |

كل الوحدات الـ22 قابلة للتحديد المستقل من القائمة في النموذجين.

## المعجم الطبي العربي

- `data/muscles/muscles.ts`: الوحدات العضلية الـ22 بالاسم الطبي العربي والإنجليزي واللاتيني، والعضلات التي تضمها كل شبكة
  بأسمائها العربية، وملاحظات حدود النموذج، وكلمات بحث شائعة (مثل «بايسبس» و«السمانة»).
- `data/anatomy/lexicon.ts`: الأسماء العربية لكل البنى غير العضلية (العظام والأعضاء والأوعية والأعصاب) وأسماء الأجهزة والجانبين.
- البحث يعمل بالعربية والإنجليزية واللاتينية، ويوحّد الهمزات والتاء المربوطة ويتجاهل التشكيل.

## التلوين والتصدير

- نوعا التلوين: **العضلات المستهدفة** `#E8602C` و**العضلات الثانوية** `#EEA585` (قابلان للتغيير)، مع لون خاص لكل عضلة عند الحاجة.
- النقر على عضلة يلوّنها بالنوع النشط، والنقر مرة أخرى يزيل اللون؛ `X` للتبديل بين النوعين.
- التصدير PNG حتى 8192 بكسل، بخلفية سوداء أو بيضاء أو شفافة، مع أسماء عربية بخطوط إشارة، ومفتاح، وعنوان اختياري.
  تظهر الأسماء فقط على العضلات المرئية فعلًا في كل منظر.
- يُضاف سطر النسبة (CC BY 4.0) أسفل كل صورة تلقائيًا. يمكن إيقافه من نافذة التصدير، وعندها يجب ذكر المصدر في مكان النشر.
- أسماء الملفات المُصدَّرة لاتينية دائمًا (مثل `muscle-studio-20261117-1704-front-back-2400x3000.png`)، لأن المتصفحات
  تستبدل الأسماء غير اللاتينية بـ`download`.

## حفظ المشاريع

يحفظ المشروع العضلات المحددة وألوانها، والجنس، والأجهزة الظاهرة، والكاميرا، وإعدادات العرض. التخزين في المتصفح افتراضيًا،
ومستودع Supabase جاهز (`supabase/migrations/0001_projects.sql` ومتغيرا `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`).
المشاريع القديمة تُفتح: تُضاف الأجهزة بقيمها الافتراضية، وتُزال العضلات غير الموجودة في النموذج الجديد مع إشعار بعددها.

## البنية

```
app/                صفحات: الرئيسية، المحرر، الرسوم المحفوظة، المكتبة، الإعدادات، المصادر والترخيص
components/         anatomy (العارض)، editor، library، export، dashboard، setup، ui
data/muscles/       الوحدات العضلية + جدول التغطية
data/anatomy/       المعجم العربي للبنى غير العضلية
data/models/        البيان (manifest) وفهرس Open Anatomy 3D
lib/anatomy/        توحيد الأسماء، ربط الشبكات بالعضلات، البحث (دون Three.js)
lib/three/          تجهيز النموذج والأجهزة و BVH والخامات والتصدير
stores/             حالة المحرر (مع التراجع/الإعادة) والنماذج والإشعارات
tests/  e2e/        اختبارات الوحدة واختبار النقر في المتصفح
```
