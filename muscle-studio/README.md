# MUSCLE STUDIO 3D — استوديو العضلات

استوديو عربي لتلوين العضلات المستهدفة والثانوية على نموذجين تشريحيين ثلاثيي الأبعاد (ذكر وأنثى)، وتصدير رسوم
توضيحية عالية الدقة للمدربين ومعلّمي التشريح. الواجهة عربية بالكامل وباتجاه RTL.

العضلات مستخرجة من **[BodyParts3D](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/)** كشبكات مستقلة لكل عضلة
وجانب، والجسم المرجعي (العظام والجلد والأعضاء) وشكل الجسم الأنثوي من **[Open Anatomy 3D](https://github.com/MervinR07/open-anatomy-3d)**.
كلاهما برخصة **CC BY 4.0** التي تسمح بالاستخدام التجاري مع ذكر المصدر — انظر [المصادر والترخيص](#المصادر-والترخيص).

## التشغيل

يتطلب Node.js ‏20.9 أو أحدث.

```bash
cd muscle-studio
npm install        # ينسخ أيضًا مفكّكات Draco/KTX2 إلى public/decoders
npm run dev        # http://localhost:3000
```

| الأمر | الغرض |
| --- | --- |
| `npm run dev` | خادم التطوير |
| `npm run build` ثم `npm start` | بناء الإنتاج وتشغيله |
| `npm test` | اختبارات الوحدة (Vitest)، ومنها تحميل ملفي GLB الأصليين والتحقق من كل عضلة |
| `npm run typecheck` / `npm run lint` | فحص الأنواع و ESLint |
| `npm run e2e:select` | اختبار النقر الحقيقي على كل عضلة في المتصفح (يتطلب Playwright وتشغيل التطبيق) |

## الظهر والكتفان (`/back`) — مجسمات Z-Anatomy الأصلية

صفحة مستقلة تعرض **ملف Blender الأصلي لمشروع [Z-Anatomy](https://github.com/Z-Anatomy/Models-of-human-anatomy)** (CC BY-SA 4.0،
مبني على BodyParts3D) مصدَّرًا بـ Blender دون تبسيط أو تقسيم أو إعادة بناء للهندسة: كل عضلة شبكة مستقلة لكل جانب بمثلثاتها
الأصلية، مع أوتارها المرسومة وجهًا بوجه، ومعرّف TA2 والاسم اللاتيني والتسلسل التشريحي والتعريف. تفاصيل الفحص والتقرير
في [`docs/ASSETS-back-shoulder.md`](docs/ASSETS-back-shoulder.md) وخط التصدير في [`pipeline/zanatomy/README.md`](pipeline/zanatomy/README.md).

- **16 عضلة مفصولة لكل جانب:** شبه المنحرفة (العلوي، الأوسط، السفلي)، الظهرية العريضة، المعينية الكبرى والصغرى، المدورة الكبرى
  والصغرى، تحت الشوكة، فوق الشوكة، تحت الكتف، الرافعة للوح الكتف، الناصبة للفقار، والدالية (الأمامي، الجانبي، الخلفي). كلها بأشكال
  المصدر الأصلية، مع ألياف تتبع اتجاه كل عضلة وأوتار وسفاق بلون عاجي كما رسمها مؤلف المجسم.
- **العظام:** لوح الكتف، الترقوة، العضد، الفقرات العنقية والصدرية والقطنية، الأضلاع، القص، الحوض والجمجمة، بلون عاجي.
- **مواضع المنشأ (قرمزي) والمرتكز (أزرق)** على العظام من بصمات Z-Anatomy، ونسبة كلٍّ منها إلى العظم الذي تقع عليه.
- **الأوتار والأربطة:** محفظة المفصل الحقاني العضدي وأربطته، الشفا الحقاني، الأربطة الأخرمية الترقوية والغرابية الترقوية، الرباط
  القفوي وفوق الشوكي، اللفافة الصدرية القطنية، الجراب تحت الأخرم وتحت الدالية.
- **الأعصاب الطرفية:** الإضافي، الكتفي الظهري، فوق الكتفي، الإبطي، تحت الكتفيان، الصدري الظهري، الصدري الطويل، جذوع الضفيرة العضدية
  وحبلها الخلفي، الكعبري، الوربية وغيرها.
- **الطبقات:** إظهار/إخفاء كل عضلة على حدة، عزل العضلة المحددة مع بقاء ما حولها ظاهرًا بشفافية والهيكل كاملًا، «بدون السطحية» و«العميقة فقط»، الهيكل العظمي وحده،
  الأعصاب والأوتار، وإعادة كل الطبقات. الانتقالات بتلاشٍ سلس.
- **عند النقر على عضلة:** تُلوَّن بلون التمييز (الافتراضي #E8602C، قابل للتغيير) على الجانبين وتظهر بطاقة عربية: الاسم (والإنجليزي واللاتيني اختياريًا)، المنشأ، المرتكز،
  الوظيفة، التعصيب، العضلات المساعدة والمضادة (قابلة للنقر)، وأزرار التركيز والعزل وإظهار المنشأ والمرتكز.
- **العرض:** خلفي، جانبي أيسر وأيمن، أمامي، قريب (العضلة المحددة أو الكتف)، دوران 360°، تكبير نحو المؤشر حتى بضعة سنتيمترات، خلفية سوداء أو كحلية؛ الإضاءة تتبع
  الكاميرا فتبقى كل زاوية مضاءة. الهوية: كحلي #0B2E6B و#173F8A مع البرتقالي #E8602C.
- **الاختبارات:** `tests/backShoulders.test.ts` (وجود كل العضلات والعظام والأعصاب، ترتيب أجزاء شبه المنحرفة، مواضع الكفة المدورة،
  الكثافة، منطق الطبقات والعزل والتلوين)، و`e2e/back-select-each.cjs` (نقر حقيقي بالفأرة على كل عضلة من الجانبين — 32 من 32 —
  مع التحقق من البطاقة والتلوين والإخفاء والعزل والهيكل والأعصاب وإعادة الضبط).
- **ما ليس في المصدر:** الرباط الغرابي الأخرمي والرباط الكتفي المستعرض العلوي غير موجودين في Z-Anatomy. أوتار الكفة المدورة جزء من
  شبكة كل عضلة (ليست شبكات مستقلة). الفروع الخلفية للأعصاب الشوكية غير ممثلة كشبكات منفصلة.

## العضلات: BodyParts3D

- **51 عضلة أو جزءًا مسمّى، شبكة مستقلة لكل جانب (102 شبكة)**، مستخرجة من ملفات OBJ الأصلية لـBodyParts3D 4.0 بخط البناء
  في `pipeline/bodyparts3d/` (طريقة إعادة البناء في [README الخاص به](pipeline/bodyparts3d/README.md)). منها:
  - الدالية: الأمامية والجانبية والخلفية منفصلة.
  - الصدرية الكبرى: الجزء الترقوي (أعلى الصدر) والقصي الضلعي والبطني.
  - شبه المنحرفة: النازل والمستعرض والصاعد (بحدود BodyParts3D).
  - العضلات الفردية للفخذ والساق والورك والكتف والعضد، وذات الرأسين وثلاثية الرؤوس والتوأمية (برؤوسها مدموجة).
- **الشكل التشريحي محفوظ:** بعد التبسيط يبقى كل سطح ضمن 0.15 مم في المتوسط (0.44 مم للمئين 95) من سطح المصدر الأصلي (`public/models/bodyparts3d/build-report.json`).
- **بقية العضلات** (378 ملفًا مستخدمًا إجمالًا) تظهر في طبقة «عضلات أخرى غير مفصولة» للعرض فقط، حتى لا تظهر فجوات.
- **غير موجودة في المصدر** (فُحصت ترويسات 2234 ملفًا): الظهرية العريضة، والمستقيمة البطنية، والمائلة الداخلية، والمستعرضة البطنية.
  من العضلات المرجعية الـ32 تتوفر 29.
- **الذكر والأنثى:** BodyParts3D جسم ذكر واحد. النموذج الأنثوي هو العضلات نفسها بعد ملاءمتها لنِسَب الهيكل العظمي الأنثوي في
  Open Anatomy 3D: تُستعاد 78,726 نقطة متطابقة بين هيكلَي النموذجين، ويُحسب منها تحويل ناعم واحد للجسم كله (Thin-Plate Spline
  منتظم على 416 معلمًا عظميًا)، فتأخذ العضلات عرض الحوض ونسب الأطراف والجذع الأنثوية دون تشويه شكل كل عضلة:
  التغيّر غير الصلب في شكل العضلة الواحدة 6.8% في الوسيط (أقصاه 13.7%)، وتمدد الحواف ≤ 1.26 للمئين 99.9 (لا تمزّق ولا طيّ).
  ويستخدم النموذج الأنثوي الهيكل العظمي المحوَّل نفسه، فتبقى العظام والجمجمة تحت العضلات تمامًا. **ليس تشريحًا أنثويًا مستقلًا**
  (لا يوجد مصدر مفتوح لعضلات أنثوية مفصولة)، بل التشريح الذكري الدقيق بنِسَب هيكل أنثوي.
- **المرجع:** يُحمَّل جسم Open Anatomy 3D الأصلي (دون تعديل) مع ملف العضلات في الإطار الإحداثي نفسه، وتُستبدل مجموعاته العضلية
  المدموجة بالعضلات المفصولة أثناء العرض. تظهر العضلات وحدها عند البدء، ويمكن إظهار الهيكل والجلد والأعضاء والأوعية والأعصاب.
- **المناظر:** أمامي وخلفي وجانبي أيسر وأيمن، مع تدوير حر.
- **المظهر: تشريح عضلي مكشوف (Écorché) طبيعي:** العضلات بلون النسيج الأحمر الوردي الطبيعي، والأوتار واللفائف بلون عاجي، والعظام
  بلونها الطبيعي، على خلفية سوداء بإضاءة استوديو ناعمة. الألوان مأخوذة من الصور المرجعية (النسيج #B0565A، الأخاديد #6B2F33،
  إبراز الألياف #D69089، الأوتار #E4DDD8). يحسب خط البناء لكل رأس ويخزّن في الملف:
  - **اتجاه الألياف** من شكل العضلة نفسها: تدرّج المسافة الجيوديسية على سطحها من أوتارها، فتتجه الألياف من منشأ العضلة إلى مدغمها
    (مروحية في الصدرية، متقاربة في الدالية، مائلة في المائلة الخارجية…).
  - **عامل الوتر** من سماكة النسيج نسبةً إلى بطن العضلة نفسها (الأوتار والصفاق رقيقة).
  - **الإظلال المحيطي** الذي يعمّق الفواصل بين العضلات.

  يرسم المظلّل الألياف بضجيج طوري متباين الاتجاه (phasor noise) يتبع ذلك الاتجاه، على مقياسين (حزم ≈ 1.3 مم وحُزيمات ≈ 5 مم)
  يخفت كلٌّ منهما قبل أن يسبب تشويشًا، مع لمعة ساتانية رطبة. لا صور ولا نسيج خارجي، فيظهر الشكل نفسه في التصدير عالي الدقة.
  العضلات المستهدفة #E8602C والثانوية #EEA585 تحتفظ بالألياف والظلال، وتبقى بقية العضلات بلونها الطبيعي.
- **غمد المستقيمة البطنية:** شبكة المائلة الخارجية في BodyParts3D تغلّف منطقة المستقيمة البطنية (غير الموجودة في المصدر). الجزء الواقع
  إنسيّ الخط الهلالي سفاقٌ (الغمد الأمامي للمستقيمة) فيظهر بلون لؤلؤي تُرى من خلاله تضاريس المستقيمة، بدل تلوينه كعضلة.
- **الرأس:** لا يحتوي BodyParts3D 4.0 أي عضلات للرأس أو الوجه، لذلك تظهر الجمجمة (من Open Anatomy 3D) افتراضيًا لإكمال الشكل،
  ويمكن إخفاؤها من «الأجهزة التشريحية».
- إذا تعذّر تحميل أي ملف تظهر رسالة خطأ واضحة **ولا يُعرض أي مجسّم بديل**.

### اختبار التحديد المستقل

- `tests/bodyparts3d.test.ts` يحمّل الجسمين مع ملفي العضلات كما يفعل التطبيق، ويتحقق من: ربط الشبكات الـ102 كلها، ووجود شبكة
  يسرى وأخرى يمنى لكل وحدة على الجانب الصحيح، وأن تحديد كل وحدة يلوّن شبكتيها فقط، وأن لكل شبكة اسمًا عربيًا، ومن مقاييس تقرير البناء.
- `e2e/select-each-muscle.cjs` ينقر بالفأرة على كل وحدة من المناظر الأربعة:

| الجسم | بالنقر على المجسّم | من القائمة فقط (مغطاة بعضلات أخرى) |
| --- | --- | --- |
| ذكر | 44 من 51 | فوق الشوكة، الصدرية الصغرى، المعينيتان، الغرابية العضدية، الألوية الصغرى، المتسعة المتوسطة، المقرّبة القصيرة |
| أنثى | 41 من 51 | الطحالية، فوق الشوكة، المدوّرتان الصغرى والكبرى، الجزء البطني من الصدرية الكبرى، الصدرية الصغرى، المعينيتان، الغرابية العضدية، الألوية الصغرى، المقرّبة القصيرة |

كل الوحدات الـ51 قابلة للتحديد المستقل من القائمة في الجسمين.

## المعجم الطبي العربي

- `data/muscles/muscles.ts`: الوحدات الـ51 بالاسم الطبي العربي والإنجليزي واللاتيني، ومصدر كل شبكة في BodyParts3D بأسمائه
  العربية، وملاحظات، وكلمات بحث شائعة (مثل «بايسبس» و«السمانة» و«أعلى الصدر»).
- `data/anatomy/lexicon.ts`: الأسماء العربية للعضلات غير المفصولة وكل البنى الأخرى (العظام والأعضاء والأوعية والأعصاب) وأسماء الأجهزة والجانبين.
- البحث يعمل بالعربية والإنجليزية واللاتينية، ويوحّد الهمزات والتاء المربوطة ويتجاهل التشكيل.

## التلوين والتصدير

- نوعا التلوين: **العضلات المستهدفة** `#E8602C` و**العضلات الثانوية** `#EEA585` (قابلان للتغيير)، مع لون خاص لكل عضلة عند الحاجة.
- النقر على عضلة يلوّنها بالنوع النشط، والنقر مرة أخرى يزيل اللون؛ `X` للتبديل بين النوعين.
- التصدير PNG حتى 8192 بكسل، بخلفية سوداء أو بيضاء أو شفافة، مع أسماء عربية بخطوط إشارة، ومفتاح، وعنوان اختياري.
  تظهر الأسماء فقط على العضلات المرئية فعلًا في كل منظر.
- يُضاف سطر النسبة (CC BY 4.0) أسفل كل صورة تلقائيًا. يمكن إيقافه من نافذة التصدير، وعندها يجب ذكر المصدر في مكان النشر.
- أسماء الملفات المُصدَّرة لاتينية دائمًا (مثل `muscle-studio-20261117-1704-front-back-2400x3000.png`)، لأن المتصفحات
  تستبدل الأسماء غير اللاتينية بـ`download`.

## حفظ المشاريع

يحفظ المشروع العضلات المحددة وألوانها، والجنس، والأجهزة الظاهرة، والكاميرا، وإعدادات العرض. التخزين في المتصفح افتراضيًا،
ومستودع Supabase جاهز (`supabase/migrations/0001_projects.sql` ومتغيرا `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`).
المشاريع القديمة تُفتح: تُضاف الأجهزة بقيمها الافتراضية، وتتحول مجموعات النموذج السابق (مثل «عضلات العضد») إلى العضلات المفصولة
التي كانت تضمها، وتُزال الوحدات التي لا مقابل لها (اليد، القدم، الحجاب الحاجز، قاع الحوض، الوربية) مع إشعار بعددها.
