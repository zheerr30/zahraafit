## الخطوات

</div>

```bash
# 1) تنزيل الملفات الرسمية (≈ 200 ميغابايت مضغوطة، لا تُضاف إلى المستودع)
B=https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST
mkdir -p bp3d && cd bp3d
curl -O $B/isa_BP3D_4.0_obj_99.zip -O $B/partof_BP3D_4.0_obj_99.zip \
     -O $B/isa_element_parts.txt -O $B/partof_element_parts.txt -O $B/README_e.html
unzip -q isa_BP3D_4.0_obj_99.zip && unzip -q partof_BP3D_4.0_obj_99.zip
cd ..

# 2) البناء (يحتاج نموذجي open-anatomy-3d الموجودين في public/models/open-anatomy-3d)
node --max-old-space-size=8000 pipeline/bodyparts3d/build.mjs --bp3d ./bp3d
```

يستغرق البناء نحو دقيقتين، ويكتب الملفين و`build-report.json`.

## ما يفعله `build.mjs`

1. **الفهرسة:** يقرأ ترويسة كل ملف OBJ (الاسم الإنجليزي، الجانب، الحدود). الملفات المعكوسة (`FJ…M`) بلا ترويسة تأخذ اسم توأمها مع قلب الجانب.
2. **الاختيار:** `units.mjs` يحدد 51 وحدة قابلة للتحديد بأسماء BodyParts3D الدقيقة، و`CONTEXT` بقية العضلات (378 ملفًا إجمالًا، كلٌّ مستخدم مرة واحدة فقط).
3. **الدمج والتبسيط:** تُدمج ملفات كل وحدة لكل جانب، وتُحوّل الإحداثيات (مم، Z للأعلى) إلى إطار open-anatomy-3d (متر، Y للأعلى، الأمام +Z)، ثم تُبسّط بـ meshoptimizer مع تصحيح اتجاه الوجوه.
4. **التحقق من الشكل:** تُقاس مسافة رؤوس المصدر الأصلية إلى السطح المبسّط لكل وحدة (`fidelity` في التقرير): أسوأ متوسط ≈ 0.38 مم، وأسوأ مئين 95 ≈ 1.6 مم.
5. **التحقق من الإطار:** تُقارن العضلات بنموذج open-anatomy-3d الذكري (≈ 0.2 مم).
6. **الجسم الأنثوي:** BodyParts3D جسم ذكر فقط. نموذج open-anatomy-3d الأنثوي هو التشريح نفسه بعد تشويهه إلى جسم MakeHuman أنثوي. نستعيد التطابق بين رؤوس نموذجيه (نفس الاتصال بترقيم مختلف، بمطابقة Weisfeiler–Lehman؛ 603,359 زوجًا وصحة مثلثات 100%)، ثم ننقل التشوّه إلى العضلات المفصولة: كل ملف مصدر يُنسب إلى البنية التي جاء منها، ويُحرَّك كل رأس بالاستيفاء المركزي (barycentric) على أقرب مثلث فيها.
   - دقة إعادة إنتاج التشوّه على أزواج محجوبة: ≈ 0.6 مم في المتوسط.
   - تمدد الحواف: الوسيط 0.92، المئين 99 ≈ 2.05 — مماثل لتشوّه open-anatomy-3d نفسه. تبقى تشوّهات موروثة في الكتفين وأعلى الظهر والوركين.
7. **الكتابة:** GLB لكل جسم بعقدتين: `muscles` (الوحدات المفصولة) و`muscles_context`، مع ضغط meshopt وتكميم.

## غير موجود في المصدر

تحقّقنا من ترويسات الملفات الـ2234 كلها: لا توجد في BodyParts3D 4.0 العضلة الظهرية العريضة، ولا المستقيمة البطنية،
ولا المائلة الداخلية، ولا المستعرضة البطنية.
