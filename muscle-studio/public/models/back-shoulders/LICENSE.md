# back-shoulders-za.glb, definitions.json — license

`back-shoulders-za.glb` is an extract of the original **Z-Anatomy** Blender file
(`Startup.blend`, https://github.com/Z-Anatomy/Models-of-human-anatomy;
Gauthier Kervyn — design, 3D, anatomy; Marcin Zielinski; Lluis Vinent), which is
based on **BodyParts3D** (© The Database Center for Life Science, DBCLS; Kousaku Okubo).

https://creativecommons.org/licenses/by-sa/4.0/
Credit: "Z-Anatomy — The libre 3D atlas of anatomy — CC-BY-SA 4.0" and
"BodyParts3D — The Database Center for Life Science".

Changes made by MUSCLE STUDIO 3D (`pipeline/blender/`): selection of the back &
shoulder region; the author's Solidify/Subdivision modifiers applied on attachment
patches, bursae and fasciae; nerve curves converted to meshes; per-structure
material primitives merged (tendon / cartilage faces kept as vertex data); baked
per-vertex appearance data (`_ANAT`, `_FIBER`); metadata (TA2 ID, Latin name,
hierarchy, Arabic name) in node extras; quantization and meshopt compression.
Muscle and bone geometry is otherwise unchanged.

`definitions.json` contains the Z-Anatomy definitions, derived from **Wikipedia**
(CC BY-SA 3.0).
