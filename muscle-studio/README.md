# MUSCLE STUDIO 3D — استوديو العضلات

استوديو عربي لتلوين العضلات المستهدفة والثانوية على نموذجين تشريحيين ثلاثيي الأبعاد (ذكر وأنثى)، وتصدير رسوم
توضيحية عالية الدقة للمدربين ومعلّمي التشريح. الواجهة عربية بالكامل وباتجاه RTL.

النموذج التشريحي للتطبيق كله (الأطلس والمحرّر، ذكر وأنثى) هو **ملف Blender الأصلي لمشروع
[Z-Anatomy](https://github.com/Z-Anatomy/Models-of-human-anatomy)** (مبني على BodyParts3D)، مصدَّرًا دون تبسيط أو إعادة بناء
للهندسة، برخصة **CC BY-SA 4.0** — انظر [المصادر والترخيص](#المصادر-والترخيص).

## التشغيل

يتطلب Node.js ‏20.9 أو أحدث.

```bash
cd muscle-studio
npm install        # ينسخ أيضًا مفكّكات Draco/KTX2 إلى public/decoders
npm run dev        # http://localhost:3000
```

| الأمر | الغرض |
| --- | --- |
| `npm run dev` | خادم التطوير |
| `npm run build` ثم `npm start` | بناء الإنتاج وتشغيله |
| `npm test` | اختبارات الوحدة (Vitest)، ومنها تحميل ملفي GLB الأصليين والتحقق من كل عضلة |
| `npm run typecheck` / `npm run lint` | فحص الأنواع و ESLint |
| `npm run e2e:select` | اختبار النقر الحقيقي على كل عضلة في المتصفح (يتطلب Playwright وتشغيل التطبيق) |

## النموذج: Z-Anatomy للجسم كاملًا

خط البناء في [`pipeline/zanatomy/README.md`](pipeline/zanatomy/README.md)، وتدقيق المناطق العشر في
[`docs/AUDIT-full-body.md`](docs/AUDIT-full-body.md). كل البنى تُصدَّر من `Startup.blend` بمثلثاتها الأصلية (3,336,025 مثلثًا في الملف
الأساسي) مع اسمها الإنجليزي واللاتيني ومعرّف TA2 وتسلسلها التشريحي وتعريفها، واسم عربي لكل بنية:

| الملف (`public/models/zanatomy/{male,female}/`) | المحتوى | التحميل |
| --- | --- | --- |
| `core.glb` | 466 عضلة (233 لكل جانب)، أوتار المؤلف، 156 لفافة وجرابًا، 354 رباطًا، 332 عظمًا وغضروفًا | دائمًا |
| `attachments.glb` | بصمات المنشأ والمرتكز على العظام | عند تشغيل الطبقة أو تحديد عضلة |
| `nerves.glb` / `organs.glb` / `vessels.glb` / `skin.glb` | الأعصاب، الأعضاء، الأوعية، مناطق الجلد | عند تشغيل الطبقة |

- **المناطق العشر:** الرأس والرقبة، الصدر، الظهر، الكتفان، الذراعان والساعدان، البطن والجذع، الحوض والألوية، الفخذ (الرباعية
  والخلفية)، المقرِّبات والمبعِّدات، الساقان. لكل عضلة طبقة عمق (سطحية/متوسطة/عميقة) محسوبة من الهندسة.
- **مظهر واحد للتطبيق كله** (`lib/three/tissue.ts`, `components/anatomy/AtlasLighting.tsx`): عضلات بلون النسيج الطبيعي بألياف تتبع
  اتجاه كل عضلة (من أوتار المؤلف أو من مواضع الارتكاز)، أوتار عاجية، عظام بغضاريفها المفصلية، لفافات وجرابات شفافة، والإضاءة نفسها
  في الأطلس والمحرّر والتصدير.
- **الأطلس `/atlas`** (و`/back` للظهر والكتفين): تحديد أي عضلة بالنقر أو البحث بالعربية، بطاقة (عربي/إنجليزي/لاتيني، TA2،
  المنطقة، الطبقة، التعريف؛ و16 بطاقة مفصّلة للظهر والكتفين بالمنشأ والمرتكز والوظيفة والتعصيب)، لون تمييز قابل للتغيير، إخفاء
  وعزل مع بقاء ما حوله شفافًا، طبقات (العضلات، الأوتار والأربطة، العظام، اللفافات، المنشأ والمرتكز، الأعصاب)، والمناظر الأمامي
  والخلفي والجانبيان والقريب، والتركيز على كل منطقة.
- **المحرّر `/editor`:** 54 وحدة قابلة للتلوين (منها الظهرية العريضة والمستقيمة البطنية والمائلة الداخلية)، كل وحدة شبكات Z-Anatomy
  الأصلية للجانبين؛ بقية العضلات تظهر كسياق ولا تُلوَّن.
- **الأنثى:** لا يوجد مصدر مفتوح لتشريح عضلي أنثوي. النموذج الأنثوي هو تشريح Z-Anatomy نفسه بعد ملاءمته لنِسَب الهيكل العظمي
  الأنثوي في open-anatomy-3d (مطابقة الهيكلين بمتوسط خطأ 3.9 مم ثم Thin-Plate Spline منتظم)، دون أعضاء تناسلية. **تقريب** وليس
  تشريحًا أنثويًا مستقلًا، ومكتوب ذلك في الواجهة.
- **ما ليس في المصدر أو تقريبي:** بعض بصمات المنشأ/المرتكز غير موجودة (لا تُولَّد)؛ 68 عضلة اتجاه أليافها من محورها لعدم وجود أوتار
  أو بصمات لها؛ نصف الشوكية الرأسية غير موجودة في الملف. نماذج الأذن الداخلية والكلية مرخّصة لغير الأغراض التجارية فلا تُصدَّر.
- إذا تعذّر تحميل أي ملف تظهر رسالة خطأ واضحة **ولا يُعرض أي مجسّم بديل**.
- **الاختبارات:** `tests/zanatomy.test.ts` (تقرير البناء، المناطق، الطبقات، ربط كل وحدة في المحرّر بجانبيها وتلوينها وحدها، أسماء عربية
  وبيانات مظهر لكل عضلة، منطق العزل)، و`e2e/back-select-each.cjs` و`e2e/select-each-muscle.cjs` (نقر حقيقي في المتصفح).

## المعجم الطبي العربي

- `data/muscles/muscles.ts`: وحدات المحرّر الـ54 بالاسم الطبي العربي والإنجليزي واللاتيني، وملاحظات، وكلمات بحث شائعة (مثل
  «بايسبس» و«السمانة» و«أعلى الصدر»).
- `pipeline/zanatomy/lexicon-ar.mjs`: الاسم العربي لكل بنية في Z-Anatomy (855 اسمًا: عضلات، أوتار ولفافات، أربطة، أعصاب، عظام)،
  مخزَّن في كل شبكة.
- البحث يعمل بالعربية والإنجليزية واللاتينية، ويوحّد الهمزات والتاء المربوطة ويتجاهل التشكيل.

## التلوين والتصدير

- نوعا التلوين: **العضلات المستهدفة** `#E8602C` و**العضلات الثانوية** `#EEA585` (قابلان للتغيير)، مع لون خاص لكل عضلة عند الحاجة.
- النقر على عضلة يلوّنها بالنوع النشط، والنقر مرة أخرى يزيل اللون؛ `X` للتبديل بين النوعين.
- التصدير PNG حتى 8192 بكسل، بخلفية سوداء أو بيضاء أو شفافة، مع أسماء عربية بخطوط إشارة، ومفتاح، وعنوان اختياري.
  تظهر الأسماء فقط على العضلات المرئية فعلًا في كل منظر.
- يُضاف سطر النسبة (Z-Anatomy, CC BY-SA 4.0) أسفل كل صورة تلقائيًا. يمكن إيقافه من نافذة التصدير، وعندها يجب ذكر المصدر في مكان النشر.
- أسماء الملفات المُصدَّرة لاتينية دائمًا (مثل `muscle-studio-20261117-1704-front-back-2400x3000.png`)، لأن المتصفحات
  تستبدل الأسماء غير اللاتينية بـ`download`.

## حفظ المشاريع

يحفظ المشروع العضلات المحددة وألوانها، والجنس، والأجهزة الظاهرة، والكاميرا، وإعدادات العرض. التخزين في المتصفح افتراضيًا،
ومستودع Supabase جاهز (`supabase/migrations/0001_projects.sql` ومتغيرا `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`).
المشاريع القديمة تُفتح: تُضاف الأجهزة بقيمها الافتراضية، وتتحول مجموعات النموذج السابق (مثل «عضلات العضد») إلى العضلات المفصولة
التي كانت تضمها، وتُزال الوحدات التي لا مقابل لها (اليد، القدم، الحجاب الحاجز، قاع الحوض، الوربية) مع إشعار بعددها.
