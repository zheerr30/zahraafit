# أدوات مشتركة (من خط BodyParts3D السابق)

لم يعد التطبيق يستخدم ملفات BodyParts3D مباشرة؛ النموذج الآن Z-Anatomy (المبني على BodyParts3D) — انظر
[`../zanatomy/README.md`](../zanatomy/README.md). بقيت هنا الأدوات التي يستخدمها خط Z-Anatomy:

- `bake.mjs`: بيانات المظهر لكل رأس (الإظلال المحيطي، عامل الوتر، اتجاه الألياف بتدرّج المسافة الجيوديسية من الأوتار أو البصمات).
- `tps.mjs`: Thin-Plate Spline منتظم لملاءمة النموذج الأنثوي.
- `lib.mjs`: أدوات هندسية (لحام الرؤوس، الشبكات المكانية).
