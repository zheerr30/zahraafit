# MUSCLE STUDIO 3D — استوديو العضلات

استوديو عربي لتلوين العضلات المستهدفة والثانوية على نموذجين تشريحيين ثلاثيي الأبعاد (ذكر وأنثى)، وتصدير رسوم
توضيحية عالية الدقة للمدربين ومعلّمي التشريح. الواجهة عربية بالكامل وباتجاه RTL.

العضلات مستخرجة من **[BodyParts3D](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/)** كشبكات مستقلة لكل عضلة
وجانب، والجسم المرجعي (العظام والجلد والأعضاء) وشكل الجسم الأنثوي من **[Open Anatomy 3D](https://github.com/MervinR07/open-anatomy-3d)**.
كلاهما برخصة **CC BY 4.0** التي تسمح بالاستخدام التجاري مع ذكر المصدر — انظر [المصادر والترخيص](#المصادر-والترخيص).

## التشغيل

يتطلب Node.js ‏20.9 أو أحدث.

```bash
cd muscle-studio
npm install        # ينسخ أيضًا مفكّكات Draco/KTX2 إلى public/decoders
npm run dev        # http://localhost:3000
```

| الأمر | الغرض |
| --- | --- |
| `npm run dev` | خادم التطوير |
| `npm run build` ثم `npm start` | بناء الإنتاج وتشغيله |
| `npm test` | اختبارات الوحدة (Vitest)، ومنها تحميل ملفي GLB الأصليين والتحقق من كل عضلة |
| `npm run typecheck` / `npm run lint` | فحص الأنواع و ESLint |
| `npm run e2e:select` | اختبار النقر الحقيقي على كل عضلة في المتصفح (يتطلب Playwright وتشغيل التطبيق) |

## العضلات: BodyParts3D

- **51 عضلة أو جزءًا مسمّى، شبكة مستقلة لكل جانب (102 شبكة)**، مستخرجة من ملفات OBJ الأصلية لـBodyParts3D 4.0 بخط البناء
  في `pipeline/bodyparts3d/` (طريقة إعادة البناء في [README الخاص به](pipeline/bodyparts3d/README.md)). منها:
  - الدالية: الأمامية والجانبية والخلفية منفصلة.
  - الصدرية الكبرى: الجزء الترقوي (أعلى الصدر) والقصي الضلعي والبطني.
  - شبه المنحرفة: النازل والمستعرض والصاعد (بحدود BodyParts3D).
  - العضلات الفردية للفخذ والساق والورك والكتف والعضد، وذات الرأسين وثلاثية الرؤوس والتوأمية (برؤوسها مدموجة).
- **الشكل التشريحي محفوظ:** بعد التبسيط يبقى كل سطح ضمن 0.38 مم في المتوسط (1.6 مم للمئين 95) من سطح المصدر الأصلي (`public/models/bodyparts3d/build-report.json`).
- **بقية العضلات** (378 ملفًا مستخدمًا إجمالًا) تظهر في طبقة «عضلات أخرى غير مفصولة» للعرض فقط، حتى لا تظهر فجوات.
- **غير موجودة في المصدر** (فُحصت ترويسات 2234 ملفًا): الظهرية العريضة، والمستقيمة البطنية، والمائلة الداخلية، والمستعرضة البطنية.
  من العضلات المرجعية الـ32 تتوفر 29.
- **الذكر والأنثى:** BodyParts3D جسم ذكر واحد. النموذج الأنثوي هو العضلات نفسها بعد نقل تشوّه الجسم الأنثوي من Open Anatomy 3D
  إليها (باستعادة 603,359 زوج رؤوس مطابقة بين نموذجيه، ودقة إعادة إنتاج ≈ 0.6 مم). **ليس تشريحًا أنثويًا مستقلًا**، ويرث تشوّهات
  ذلك التحويل في الكتفين وأعلى الظهر والوركين.
- **المرجع:** يُحمَّل جسم Open Anatomy 3D الأصلي (دون تعديل) مع ملف العضلات في الإطار الإحداثي نفسه، وتُستبدل مجموعاته العضلية
  المدموجة بالعضلات المفصولة أثناء العرض. تظهر العضلات وحدها عند البدء، ويمكن إظهار الهيكل والجلد والأعضاء والأوعية والأعصاب.
- **المناظر:** أمامي وخلفي وجانبي أيسر وأيمن، مع تدوير حر.
- **المظهر الواقعي (الافتراضي):** يحسب خط البناء لكل رأس في العضلات قيمتين ويخزّنهما في الملف: الإظلال المحيطي (يُظلّل
  الفواصل بين العضلات) وسماكة النسيج (المناطق الرقيقة = أوتار ولفائف تظهر بلون أبيض عاجي)، إضافة إلى اتجاه الألياف. يرسم المظلّل
  ألياف العضلة على طول محورها مع لمعة رطبة خفيفة. كل ذلك من شكل BodyParts3D نفسه دون صور خارجية، ويظهر في التصدير أيضًا.
  وضع «أبيض الاستوديو» يستخدم الظلال والألياف نفسها بخامة بيضاء.
- **الرأس:** لا يحتوي BodyParts3D 4.0 أي عضلات للرأس أو الوجه، لذلك تظهر الجمجمة (من Open Anatomy 3D) افتراضيًا لإكمال الشكل،
  ويمكن إخفاؤها من «الأجهزة التشريحية».
- إذا تعذّر تحميل أي ملف تظهر رسالة خطأ واضحة **ولا يُعرض أي مجسّم بديل**.

### اختبار التحديد المستقل

- `tests/bodyparts3d.test.ts` يحمّل الجسمين مع ملفي العضلات كما يفعل التطبيق، ويتحقق من: ربط الشبكات الـ102 كلها، ووجود شبكة
  يسرى وأخرى يمنى لكل وحدة على الجانب الصحيح، وأن تحديد كل وحدة يلوّن شبكتيها فقط، وأن لكل شبكة اسمًا عربيًا، ومن مقاييس تقرير البناء.
- `e2e/select-each-muscle.cjs` ينقر بالفأرة على كل وحدة من المناظر الأربعة:

| الجسم | بالنقر على المجسّم | من القائمة فقط (مغطاة بعضلات أخرى) |
| --- | --- | --- |
| ذكر | 44 من 51 | فوق الشوكة، الصدرية الصغرى، المعينيتان، الغرابية العضدية، الألوية الصغرى، المتسعة المتوسطة، المقرّبة القصيرة |
| أنثى | 41 من 51 | الطحالية، فوق الشوكة، المدوّرتان الصغرى والكبرى، الجزء البطني من الصدرية الكبرى، الصدرية الصغرى، المعينيتان، الغرابية العضدية، الألوية الصغرى، المقرّبة القصيرة |

كل الوحدات الـ51 قابلة للتحديد المستقل من القائمة في الجسمين.

## المعجم الطبي العربي

- `data/muscles/muscles.ts`: الوحدات الـ51 بالاسم الطبي العربي والإنجليزي واللاتيني، ومصدر كل شبكة في BodyParts3D بأسمائه
  العربية، وملاحظات، وكلمات بحث شائعة (مثل «بايسبس» و«السمانة» و«أعلى الصدر»).
- `data/anatomy/lexicon.ts`: الأسماء العربية للعضلات غير المفصولة وكل البنى الأخرى (العظام والأعضاء والأوعية والأعصاب) وأسماء الأجهزة والجانبين.
- البحث يعمل بالعربية والإنجليزية واللاتينية، ويوحّد الهمزات والتاء المربوطة ويتجاهل التشكيل.

## التلوين والتصدير

- نوعا التلوين: **العضلات المستهدفة** `#E8602C` و**العضلات الثانوية** `#EEA585` (قابلان للتغيير)، مع لون خاص لكل عضلة عند الحاجة.
- النقر على عضلة يلوّنها بالنوع النشط، والنقر مرة أخرى يزيل اللون؛ `X` للتبديل بين النوعين.
- التصدير PNG حتى 8192 بكسل، بخلفية سوداء أو بيضاء أو شفافة، مع أسماء عربية بخطوط إشارة، ومفتاح، وعنوان اختياري.
  تظهر الأسماء فقط على العضلات المرئية فعلًا في كل منظر.
- يُضاف سطر النسبة (CC BY 4.0) أسفل كل صورة تلقائيًا. يمكن إيقافه من نافذة التصدير، وعندها يجب ذكر المصدر في مكان النشر.
- أسماء الملفات المُصدَّرة لاتينية دائمًا (مثل `muscle-studio-20261117-1704-front-back-2400x3000.png`)، لأن المتصفحات
  تستبدل الأسماء غير اللاتينية بـ`download`.

## حفظ المشاريع

يحفظ المشروع العضلات المحددة وألوانها، والجنس، والأجهزة الظاهرة، والكاميرا، وإعدادات العرض. التخزين في المتصفح افتراضيًا،
ومستودع Supabase جاهز (`supabase/migrations/0001_projects.sql` ومتغيرا `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`).
المشاريع القديمة تُفتح: تُضاف الأجهزة بقيمها الافتراضية، وتتحول مجموعات النموذج السابق (مثل «عضلات العضد») إلى العضلات المفصولة
التي كانت تضمها، وتُزال الوحدات التي لا مقابل لها (اليد، القدم، الحجاب الحاجز، قاع الحوض، الوربية) مع إشعار بعددها.

## البنية

lib/three/          تجهيز النموذج والأجهزة و BVH والخامات والتصدير
stores/             حالة المحرر (مع التراجع/الإعادة) والنماذج والإشعارات
tests/  e2e/        اختبارات الوحدة واختبار النقر في المتصفح
